\section{Group Project Requirement}
\label{sec:requirement}

This group studies two datasets from the UCI Machine Learning Repository: Statlog German Credit Data and the sick subset of the Thyroid Disease collection~\cite{dua2019uci,uci_credit_g_1994,uci_thyroid_1986}. Each dataset will follow a documented preprocessing, modeling, and evaluation workflow. The report will compare the datasets and include four supervised algorithms, an association-rule component, cross-validation, an independent evaluation protocol, figures, and a reproducible comparison table.
