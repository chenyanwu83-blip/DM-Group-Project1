## 一、讲稿正文（英文 · 2′30″ · 约 350 词，[ ] 内为中文提示，不讲出）

### [0:00–0:30 · sick 是什么]
> Now, dataset B — **sick**, from the UCI Thyroid Disease repository. It contains
> **3,772 patient records with 30 attributes**, screening for thyroid disease.
> The classes are highly imbalanced: 3,541 negative versus only 231
> sick-euthyroid — roughly **94 to 6**. One wording note we keep strict:
> "negative" means *no thyroid abnormality detected in this screening*, not
> "perfectly healthy"; and the positive class, sick-euthyroid, is **not**
> hypothyroidism. We treat "sick" as the positive class throughout.

【要点：94:6 是全项目不平衡主线的"重"端；两条语义红线体现严谨，评审爱问】

### [0:30–1:30 · 数据质量专题：缺失机制与处理]
> The defining challenge of this dataset is **missingness** — 6,064 cells,
> 5.4% of the data. The audit revealed a clean mechanism: every lab test
> comes as a pair — a "measured" flag and the value itself. If the flag says
> *false*, the value is missing **by design**: the test was never performed.
> The extreme case is **TBG — 100% missing in all 3,772 records**. A pairing
> audit across all six lab pairs found **zero anomalies**: the data is
> incomplete, but internally consistent. So the handling follows the
> mechanism: TBG and its constant flag are **removed** — you cannot impute a
> column that was never observed. Beyond TBG, 29.9% of rows still carry
> missing values, and a controlled experiment settled how to handle them:
> deleting those rows **throws away 30% of the patients — including 19
> positive cases — for no statistical F1 gain** and a lower AUC. So we
> impute instead, **inside the pipeline, on training folds only**.

【要点：机制→决策一一对应；"删行亏 30% 还不涨分"是本段金句】

### [1:30–2:10 · 防泄漏]
> Where the imputation happens matters: **every pre-processing step —
> imputation, encoding, scaling, and SMOTE — lives inside the pipeline**,
> fitted only on each training fold. Validation folds are transformed, never
> fitted. The whole group shares **locked cross-validation splits**, so every
> number in this project is directly comparable. As a sanity check, an
> equal-cost configuration reproduces the plain baseline exactly.

【要点：防泄漏是课程红线，用"试金石"一句收尾显示自信】

### [2:10–2:30 · 集成彩蛋 + 交棒]
> Finally, one teaser from the exploratory ensemble study I ran: **AdaBoost
> plus SMOTE pushed F1 to 0.937 with AUC 0.999**, beating the main-matrix
> champion; and the pre-specified test confirms **re-weighting beats
> re-sampling** on this data. Now **C** will take you through the models.

【要点：0.937 与 p=6.4e-4 都有 C10/C11 背书；交棒词按实际顺序改成当天的下一位】

## 三、预期问答（人手 2+1，11-05 前随题库交 E）

1. **Why not drop the 61 duplicate rows?**
   → 对齐 UCI 官方 3,772 口径（删了全组哈希与切分锚点作废）；已在报告 ch3 披露为数据质量问题。
2. **What if SMOTE were outside the CV loop?**
   → 合成样本会泄入验证折、指标虚高；我们的 SMOTE 全部在 imblearn Pipeline 折内合成（C10 复核记录可查）。
3. **整体题：Why these two datasets?**
   → 五维对比（规模 1,000 vs 3,772 / 不平衡 70:30 vs 94:6 / 缺失 0 vs 5.4% / 属性构成 / 领域），支撑 RQ1–4；集成研究再贡献一次"赢家翻转"（ada 在 sick 登顶、credit-g 不复现）。
