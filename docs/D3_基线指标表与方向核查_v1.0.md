## 1. 核查方法（独立复算，不采信 C 的自检结论）

对 10 个配置（2 数据集 × 4 模型 plain + 2 个 ZeroR 参照）× 2 协议（cv10 / holdout）共 20 个结果单元，执行 326 项检查，分五类：

1. **模板与口径**：summary/folds 列名与 D2 模板逐列相等；`pos_label/neg_label` 与 D1 映射一致（credit-g=bad/good，sick=sick/negative）；seed=42；`data_sha256` 与 `split_manifest.json` 逐一相符。
2. **折级一致性与聚合复算**：每折 TN+FP+FN+TP=n_eval；credit-g 每折代价 =(5×FN+1×FP)/N；summary 的 mean/std(ddof=0)/n_valid 由 folds 独立重算比对；合并混淆矩阵 = 各折之和；holdout 行 std 全空。
3. **行覆盖 = 锁定切分**：cv10 预测的 `row_idx` 恰好是全量行各一次；holdout 预测的 `row_idx` 集合与 D2 锁定的 `holdout_idx_*.csv` 完全相等。
4. **标签方向（最硬证据）**：preds 里的 `y_true` 与 `data/raw` 原始 CSV 同一行的标签**逐行全等**（20/20 单元零错行）；`proba_pos` 落在 [0,1]；正类样本的 `proba_pos` 均值 > 负类样本（概率列方向未接反）。
5. **汇总复算**：用 D2 `evaluate.py::compute_metrics` 直接吃 preds 的 `(y_true, y_pred, proba_pos)`，复算的混淆矩阵、accuracy、credit-g 总代价与 summary 落盘值逐位一致；holdout 的标签构成与 manifest 的 `test_label_counts` 一致（credit-g 210/90，sick 1063/69）。

## 2. 核查结果

**326 项检查全部 PASS，0 FAIL。** 唯一需要说明的是概率-预测边界一致性检查中的 6 处良性例外（已带数字记录在 `d3_direction_check_v1.csv`）：

| 配置 | 协议 | 现象 | 定性 |
|---|---|---|---|
| credit-g SVC | cv10 / holdout | 37/1000、14/300 行"预测 good 但 proba_pos≥0.5"，偏差 ≤0.063 | SVC `probability=True` 的 Platt 标定概率与决策函数 `predict` 在 0.5 附近存在已知少量不一致；全部单侧、带内 |
| sick SVC | cv10 / holdout | 15/3772、5/1132 行同上，偏差 ≤0.084 | 同上 |

判定依据：①"预测正类但 proba_pos<0.5"的硬违规 **0 例**（若概率列接反，此项会系统性爆炸）；②类别分离检查全过；③C4-2 已证 threshold 与 plain 的 AUC 逐位相等（同一概率向量）；④所有例外均在 0.10 边界带内且单侧。**结论：标签方向与概率列方向核查通过，plain 结果可信，M2 的方向核查欠账就此补齐。**

## 4. RQ2 标注：accuracy 与 F1/AUC 排名分歧

排名仅在 4 模型内比较（ZeroR 为参照不入排）。分歧 = accuracy 排名与 F1 或 AUC 排名不一致：

| 数据集 / 协议 | 分歧案例（RQ2 证据） |
|---|---|
| credit-g / cv10 | **SVC** accuracy 第 1（0.7680）但 F1 第 3（0.4979）；**Logistic** accuracy 第 3（0.7520）但 Recall/F1 第 1（0.4700/0.5307），且总代价最低（0.8840） |
| credit-g / holdout | **SVC** accuracy 第 1（0.7600）但 F1 第 2、总代价 0.9733；**Logistic** accuracy 第 2（0.7400）但 F1/AUC/Recall 全第 1，总代价 0.8867 全场最低 |
| sick / cv10 | 无分歧（RF 四项全第 1） |
| sick / holdout | **DecisionTree** accuracy 第 1（0.9867）但 Recall/AUC 第 2（RF 以 0.8551/0.9982 反超，F1 两者仅差 0.0013） |

**多数类基线的"欺骗性"（RQ2 核心证据）**：
- sick 上 ZeroR 什么也不预测，accuracy 高达 **0.9388/0.9390**，但正类 Recall=F1=**0**（231/69 个 sick 全部漏报）——94:6 不平衡下 accuracy 完全失效；
- credit-g 上 ZeroR accuracy 0.7000 看似"七成正确"，但总代价 **1.5000** 是全表最差（所有 bad 全漏，5×FN 代价拉满），任何真实模型的代价都优于它；
- 结合 C4-2 的 threshold 结果（credit-g RF 代价降至 0.604、recall 翻倍），"accuracy 最优 ≠ 代价/召回最优"的叙事链已齐，供 ch6 与 RQ2 写作直接引用。
