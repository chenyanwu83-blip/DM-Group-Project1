## 3. 标签口径声明（D1 §正类约定）

- `y` 全程保留原始字符串标签（`bad/good`、`sick/negative`），**不做 0/1 编码**；
- 因此 `class_weight` 直接用冻结规格原键；若键与类名不符，sklearn 在 `fit` 时直接报错（保留字符串标签 = 免费自检）；
- 送指标库时 `y_true / y_pred / classes_` 同源同类型；2D 概率必传 `classes=est.classes_`（且 classes_ 与概率来自同一个已训练 estimator）。
