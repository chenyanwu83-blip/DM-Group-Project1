# Figure and table rules

- Use the course template's automatic figure and table numbering.
- Source files: `fig_<owner>_<topic>.pdf` for vector figures; PNG only where PDF is unsuitable.
- Captions should identify the dataset, analysis protocol, strategy or model, metric, and positive class when relevant.
- Every figure and table must be cited and interpreted in the surrounding report text.
- Figures about class imbalance must show counts or percentages and state which label is positive.
- Results tables must distinguish 10-fold CV from 70:30 holdout results. Do not mix them in one unlabeled column.
- Record the underlying result file for each figure so D can check reported numbers.
- Do not paste hypothetical example values from the group guide into the final report.
