## 1. 方法与口径

对 84 个结果单元（主矩阵 34 配置 × 2 协议 = 68 + 集成 8 配置 × 2 协议 = 16）共执行 **1024 项检查**，每单元 12–16 项：

1. **模板与口径**：summary/folds 列名与 D2 模板逐列相等；pos/neg 标签与 D1 映射一致；seed=42；`data_sha256` 与 `split_manifest.json` 相符；折数 10/1；protocol 字段正确。
2. **聚合双侧复算（本表核心口径）**：summary 的 mean / **std(ddof=0)** / n_valid 全部由 folds 独立重算逐位比对；每折 TN+FP+FN+TP=n_eval；credit-g 每折代价 =(5×FN+FP)/N；合并混淆矩阵 = 各折之和；holdout 行 std 全空。
3. **preds 覆盖行数**：cv10 = 全量行数（1000/3772），holdout = 锁定 `holdout_idx_*.csv` 行数（300/1132）。标签方向逐行核查已在 D3（plain）与 C10（集成）完成，此处不重复。
4. **τ 解析（兑现 D3 §5.2 承诺）**：threshold 配置从 folds `notes`（唯一事实来源）解析 `tau=`，cv10 记为 `tau_min`–`tau_max`（每折可不同），holdout 单值。summary 不存 τ 副本，不要求 C 改格式。
5. **RQ2 标注规则（预注册式，写死在脚本）**：`accuracy_mean ≥ 0.70 且 recall_mean ≤ 0.40` → `acc_high_recall_low`；ZeroR 参照行同规则命中者标 `zero_ref_trap`。
6. **runtime_sec**：取自各 summary 落盘值（全精度）；C6 `run_log_v1.csv` 为 3 位小数展示口径，两者同源。credit-g 总代价单列（`cost_mean/cost_std/cost_pooled`）；sick 不报代价（D1 §指标）。

## 2. 核查结果

**1024 项检查全部 PASS，0 FAIL。** 84/84 单元 `audit=PASS`。两处需要说明的观察（均非 FAIL，文件自洽）：

- sick 侧 cost 策略与 plain 的**合并混淆矩阵逐位相同**（DT/LR/SVC × 双协议 6 单元；RF 有差异：cv10 F1 0.8703→0.8728，holdout 0.8806→0.8971）。即 94:6 不平衡下，代价加权未翻转这三个模型在 0.5 决策边界附近的任何一张预测。已如实入表，供 D6/D7 归因讨论（对照 credit-g 侧 cost 全模型 recall +0.34~0.59 的强效果，"同一策略跨数据集效果翻转"又添一例）。
- threshold 与 plain 的 AUC 在全部 16 单元逐位相等（与 C4-3 锚点核对结论一致，本表再次独立确认：τ 只动决策阈值、不动概率排序）。

## 6. 关键观察（供 D6 对比表 / D7 sec6 直接引用）

1. **策略增益方向一致、幅度数据集翻转**：credit-g 上三类策略（smote/cost/threshold）全部大幅抬 recall 降代价（lr_cost 代价 0.5140 为全表最低）；sick 上 smote 对 LR 是净伤害（F1 0.6867→0.5211，acc 0.9666→0.9016）而 RF 受益（0.8703→0.8972）——与"one-hot×SMOTE 插值在稀疏空间拖垮线性模型 / RF 对插值稳健"的 bagging 归因互洽。
2. **cost 在 sick 近似恒等映射**（§2）：代价加权在 94:6 极不平衡下没翻动 DT/LR/SVC 任何预测，与 credit-g 的强效果形成跨数据集对照。
3. **accuracy 与 F1/代价排名系统性分歧**（RQ2，§4）。
4. **集成赢家翻转**（§5）：小而噪的 credit-g → 线性+代价敏感赢；大而干净的 sick → 集成+重采样赢。
