# CDS 535 report section map

Use the actual course template as the formatting authority. The group V3.1 plan assigns these files:

| File | Owner | Content |
| --- | --- | --- |
| `main.tex` | E | Title page, abstract, keywords, section inputs |
| `sections/sec1_requirement.tex` | E | Project scope and division of work |
| `sections/sec2_introduction.tex` | A | Motivation, objectives, research questions |
| `sections/sec3a_creditg.tex` | A | credit-g source, schema, quality, preprocessing |
| `sections/sec3b_sick.tex` | B | sick source, missingness, preprocessing |
| `sections/sec4_algorithms.tex` | C | Four classifiers and imbalance strategies |
| `sections/sec5_training.tex` | C | Pipelines, settings, validation protocols |
| `sections/sec6_results.tex` | D | Metrics, figures, cross-dataset comparison |
| `sections/sec6x_unsupervised.tex` | E | Apriori settings, rules, interpretation |
| `sections/sec7_conclusion.tex` | D and E | Findings, limits, future work |
| `sections/sec8_contribution.tex` | E | Member IDs, specific work, workload shares |
| `references.bib` | E maintains | Dataset, tool and literature citations |

The teacher's required content still has to appear even if the template has different chapter names. In particular, include data provenance and licences, tasks performed, direct cross-dataset analysis, and member contributions.

Before inviting editors, compile the original template once, copy it, add the section files one at a time, and compile again. Copying a project does not copy the original collaborators.
