# sick 标签语义说明 + 数字复核表

## 标签语义

| 标签值 | 含义 | 角色 |
|---|---|---|
| `sick` | sick-euthyroid：甲状腺功能本身正常（euthyroid），但甲状腺相关化验异常（尤其 T3 偏低）；甲状腺腺体本身无病变，多由慢性肾衰、糖尿病、贫血等**严重非甲状腺疾病**引起（UCI thyroid.theory）。≠ 甲减 | 正类（少数类，231 条） |
| `negative` | 本次甲状腺疾病筛查未检出异常 | 负类（多数类，3,541 条） |

- 注意 1：sick-euthyroid 不等于 hypothyroid（甲减是另一个子数据集 hypothyroid.arff），不能简写为「是否甲减」。
- 注意 2：negative 只表示本次筛查未见甲状腺异常，不能解读为「完全健康」。
- 正类定义（D1 评估协议）：pos_label='sick'；所有 P/R/F1 以 sick 为正类计算。
