## 2. 方法（一次性锁定）

**Nadeau & Bengio (2003) 方差校正的折级配对 t 检验**（对应 Weka Experimenter 的 corrected resampled t-test），同折配对 k=10：

```text
d_f = x_f − y_f ;  d̄ = mean(d) ;  s² = var(d, ddof=1)
Var(d̄) = s² × (1/k + n_test/n_train)        ← NB 校正
t = d̄ / √Var(d̄) ;  df = k−1 = 9 ;  p = 2·t.sf(|t|, 9)     (scipy.stats.t.sf, V3 指定实现)
```

- n_test/n_train 用**实际锁定折表**：credit-g 100/900、sick 377.2/3394.8（均值口径）→ 方差系数 1/k+n_te/n_tr = **0.2111 = 朴素配对 t 的 2.11 倍**（10 折理论值 1+10/9 ✓）。这是有意保守：朴素折级 t 在重叠训练集上虚增显著性。
- 指标范围 **accuracy / recall / f1 / auc**（对应 RQ1 策略增益、RQ2 指标分歧；kappa/balanced/macro 未入检验，需要时按同框架追加即可）。
- **边界不造数**：逐折逐位相同的配对（见锚点⑤⑥）→ p=1.0、note=`identical`，不输出虚构 t；方差为零的常数差 → t 发散、p 置 NaN 并 note 标注。
- **多重比较**：pairs 表族内（数据集×指标全部 120 对）给 **Holm(1979) 校正 p**；星号按**原始 p**（α=0.05）标注。报告端呈现口径（报 raw 还是 Holm、报哪些对）由 D6 按 D1"注明多重比较"决定。
- **跨数据集**：不同样本无法同折配对，**不做跨数据集 t 检验**；key 表两侧并列仅供 D6 描述性对比（"赢家翻转"叙事用）。

## 7. 勘误（2026-10-27）：Holm 表述按族分述

本节为叙述勘误，**数字与表零改动**；触发来源与 D 的 af8d4e3 勘误同源（D7 §6 委托兑现核查时发现同类问题），下述计数已用本表 pairs CSV 重算两路验证（D 一路、C 终检一路，逐项一致）。

### 勘误一：§3/§5 "credit-g 过 Holm 仅 dt_smote vs lr_smote 一对" —— 仅对 F1 族成立

原句把 F1 族的结论说成了全族。正确的**按族分述**（族 = 数据集 × 指标，Holm 在每族 120 对内校正）：

| 数据集 | 指标族 | 全配对过线 | 预指定 12 对照过线 |
|---|---|---|---|
| credit-g | F1 | **1**（dt_smote vs lr_smote，p_holm=0.021） | 0/12 |
| credit-g | recall | **47** | **8/12**（7 对 cost/threshold：dt_cost 0.0088 / dt_threshold 0.0129 / rf_cost 0.0046 / rf_threshold 0.0038 / lr_cost 0.0011 / lr_threshold 0.0073 / svc_cost 0.0084；另 1 对 lr_smote 0.046） |
| credit-g | accuracy | 15 | 3/12 |
| credit-g | AUC | 2 | 0/12 |
| sick | F1 | 22（几乎全为胜过 lr_smote/svc_smote 的跨模型对） | 0/12 |
| sick | recall | 18 | 2/12（dt_smote、svc_smote） |
| sick | accuracy | 26 | 1/12 |
| sick | AUC | 24 | 0/12 |

recall 族 8/12 预指定对照过 Holm 反而是策略实验的**更强证据**（召回增益在多重比较校正下稳健），原句把这部分也一并抹掉了。

### 勘误二：§5 与 C5-2 提交信息（471bdb9）"sick 的 lr_smote 崩盘两种口径都稳" —— vs-plain 不过 Holm

- sick **lr_plain vs lr_smote**（f1）：Δ=−0.1656，raw p=0.0022 显著，但 **p_holm=0.208 不过线**（sick F1 族 120 重校正后）。
- "LR+SMOTE 崩盘"在 Holm 口径下的稳健支撑是**跨模型对**：8 对以 lr_smote 为输家的跨模型对过 Holm（最小 rf_plain vs lr_smote，p_holm=2.1e-6）。
- 正确表述：**"崩盘结论跨模型意义上 Holm 稳健；vs-plain 仅 raw p 显著（Holm 后 0.208）"**。
